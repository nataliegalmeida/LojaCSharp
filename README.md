# LojaCSharp

Meu primeiro projeto desenvolvido em C# durante meus estudos de Engenharia de Software.

## Aula 1 — Variáveis e tipos de dados

Nesta atividade, pratiquei:

- Declaração de variáveis;
- Tipo string;
- Tipo int;
- Tipo double;
- Exibição de informações no console com Console.WriteLine().

## Tecnologias

- C#
- .NET 10

## Como executar

No terminal, dentro da pasta do projeto, execute:

dotnet run
